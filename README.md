# data-analyst-portfolio

SQL, Python and BI projects I'm building as I move into data analytics.

I'm Makiko Tsuda. I spent over 10 years building and running certification programs, including scaling UiPath's certification portfolio from 2 to 12 certifications. The part of that work I kept gravitating toward was the data: the dashboards, the KPI reporting and the cross-source analysis that showed whether a program was actually working. I now work in customer support for RTSM (randomization and trial supply management) software used in clinical trials, where solving a customer's problem often starts with tracing it through the data. This repo is where I'm building analytics into a standalone skill set: real questions, answered end to end and documented.
